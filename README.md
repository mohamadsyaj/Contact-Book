# Contact Book

A simple and responsive contact management application built with React and Vite.

Users can add contacts, search through them in real time, and delete entries using a clean and minimal interface.

---

## Features

- Add new contacts
- Real-time search and filtering
- Delete contacts
- Responsive UI design
- Component-based React architecture
- Fast development environment using Vite

---

## Tech Stack

- React 19
- Vite
- JavaScript (ES6+)
- CSS3

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate into the project directory:

```bash
cd contact-book
```

Install dependencies:

```bash
npm install
```

---

## Running the Application

Start the development server:

```bash
npm run dev
```

Then open the local URL provided in the terminal (usually):

```bash
http://localhost:5173
```

---

## Build for Production

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

---

## Functionality Overview

### Add Contacts
Users can create contacts with basic information such as name and email.

### Search & Filter
The application filters contacts instantly while typing.

### Delete Contacts
Contacts can be removed dynamically from the contact list.
